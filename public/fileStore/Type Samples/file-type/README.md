# file-type Test Fixtures

These files are test fixtures from the [file-type](https://github.com/sindresorhus/file-type) project by Sindre Sorhus.
They are copied unchanged from its `fixture` folder at commit
[`11e0d64`](https://github.com/sindresorhus/file-type/tree/11e0d6473a37972e4d39d8d6c1c9d1b85b9ace25/fixture) (14 October
2026). Each file matches the git hash of its original.

They are here to test file type detection against files made by the applications themselves, alongside the DPUse
samples in the parent folder. They are small and hold little data.

## Files

| File                             | Format                                              |
| -------------------------------- | --------------------------------------------------- |
| `fixture.arrow`                  | Apache Arrow                                        |
| `fixture.avro`                   | Apache Avro                                         |
| `fixture.ods`                    | OpenDocument spreadsheet                            |
| `fixture.parquet`                | Apache Parquet                                      |
| `fixture.sav`                    | SPSS statistical data                               |
| `fixture.sqlite`                 | SQLite database                                     |
| `fixture.xlsx`                   | Excel workbook                                      |
| `fixture2.xlsx`                  | Excel workbook with its content types entry last    |
| `fixture-office365.xlsx`         | Excel workbook saved by Office 365                  |
| `fixture.xlsm`                   | Excel macro-enabled workbook                        |
| `fixture.xml`                    | XML, UTF-8                                          |
| `fixture-utf8-bom.xml`           | XML, UTF-8 with a byte order mark                   |
| `fixture-utf16-le-bom.xml`       | XML, UTF-16 little-endian with a byte order mark    |
| `fixture-utf16-be-bom.xml`       | XML, UTF-16 big-endian with a byte order mark       |
| `fixture.xls.cfb`                | Excel 97–2003 workbook, named as file-type names it |
| `fixture-password-protected.xls` | Excel 97–2003 workbook, password protected          |
